# AGENTS.md

## Purpose

This repository is Luyi's shared work knowledge base.

It is intended to be used by multiple AI tools, including personal and company AI environments.

## Basic Rules

1. Read `START_HERE.md` first if it exists.
2. Read `index.md` before searching individual wiki pages if it exists.
3. Treat the latest confirmed information as higher priority than older information.
4. Do not present assumptions as confirmed facts.
5. If new information conflicts with existing content, flag the conflict instead of silently overwriting it.
6. Raw source files are reference materials and should not be modified unless explicitly requested.
7. Confirmed reusable knowledge should be organized into the Wiki instead of remaining only in chat history.

## Wiki Maintenance

When new information is confirmed:

- Update the relevant Wiki page.
- Update `index.md` if a new page is created.
- Add a short record to `log.md` for major updates.
- Avoid unnecessary duplication across multiple pages.

## Working Style

Outputs should be:
- structured
- data-driven
- practical
- clear about assumptions, risks and opportunities
- focused on actionable conclusions

## Stakeholder Profiles

Stakeholder information should be treated as a working profile, not a personality label.

Focus on:
- role and responsibilities
- key concerns
- communication style
- working preferences
- effective ways to drive execution
- collaboration boundaries
